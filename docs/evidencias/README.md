# Evidências da atividade

Esta pasta organiza as evidências visuais e técnicas da implementação. Salve as capturas do emulador com nomes descritivos, sem incluir dados pessoais desnecessários.

## Capturas esperadas

- `01-lista-inicial.png` — tela inicial com a lista de tarefas.
- `02-cadastro.png` — formulário de nova tarefa.
- `03-tarefa-cadastrada.png` — tarefa exibida após o cadastro.
- `04-edicao.png` — formulário preenchido para editar uma tarefa.
- `05-tarefa-concluida.png` — tarefa marcada como concluída.
- `06-exclusao.png` — lista após excluir uma tarefa.
- `07-navegacao.png` — fluxo entre lista e formulário.

## Validação técnica

- `build.txt` — saída do build/teste executado localmente.

As capturas devem mostrar a interface inteira e textos legíveis. Não inclua APKs, pastas de build, caches ou configurações locais da IDE no repositório.
